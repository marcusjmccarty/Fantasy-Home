ABOUT GRIDIRON/86

A compact fantasy football dashboard inspired by monochrome workstation software of the 1980s. Built with plain HTML, CSS, and JavaScript.

Live leagues: Connect ESPN via the Cloudflare bridge or use the read-only Sleeper API. Team history, ranks, matchup points, and individual player scoring are calculated from your league's data.

Other leagues: Import a correctly structured JSON file; no external account integration is implied.

Important: In-progress weekly totals can change. If past player-level details are missing from the provider, this terminal displays a dash rather than inventing stats. Demo figures are fictional.
KEYBOARD SHORTCUTS

Every part of GRIDIRON/86 works from the keyboard. Single keys work when focus is not in a text field or menu. Ctrl+K (⌘K on Mac) opens the command palette from anywhere.

Turn these off if you use speech input or a screen reader that sends single keys. Ctrl+K, Esc, arrow keys and Tab always work. Remembered in this browser.
